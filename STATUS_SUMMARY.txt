🚀 الخطوات التالية:
────────────────────────────────────────────────────────────────────────────

1. تثبيت الحزم:
   cd server
   npm install
   cd ../mobile
   npm install

2. تشغيل السيرفر:
   cd server
   npm run dev
   
   ✅ السيرفر سيعمل على: http://localhost:5000/api

3. تشغيل التطبيق:
   cd mobile
   npm start
   
   اختر: android / ios / web

4. اختبار الـ API:
   استخدم Postman أو curl لاختبار النقاط:
   - POST /api/auth/login
   - POST /api/auth/register
   - GET /api/auth/me
