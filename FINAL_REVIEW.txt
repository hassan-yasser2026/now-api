                            🚀 التعليمات الأولية
═══════════════════════════════════════════════════════════════════════════════

1️⃣ تثبيت الحزم:
   cd server
   npm install

2️⃣ إعداد قاعدة البيانات:
   npm run seed

3️⃣ تشغيل السيرفر:
   npm run dev
   
   السيرفر سيعمل على:
   🌐 http://localhost:5000
   📡 API: http://localhost:5000/api

4️⃣ تشغيل التطبيق المحمول:
   cd mobile
   npm install
   npm start
   
   اختر المنصة:
   • android - تشغيل على محاكي Android
   • ios - تشغيل على محاكي iOS
   • web - تشغيل على المتصفح
